# 回归测试库：5 支 2024-2025 热门新股 backtest

> 用 SKILL.md 8 步流程跑 5 支已上市新股，严格按「招股期视角」给出立场，再 reveal 实际表现并复盘。这套案例展示 skill 在不同质地标的上的判断模式，校准未来 forward case 的深度和审慎度。

## 测试方法

1. **不偷看后续股价**：搜索时只用招股期能拿到的信息（招股书、当时新闻、当时基石名单）
2. **严格 9 步流程**（含新增的 Step 9 持仓后管理）：不偷懒、不跳步、不为已知结果反向 fit 立场
3. **明确立场 + 持仓管理 + 后期 reveal**：先写到「持仓管理建议」为止，再揭示实际表现
4. **复盘标的本身**：纯标的分析复盘，不是 skill 改进文档

## 怎么用这个 backtest 持续迭代

每写一个新 case（无论是 forward 真实新股还是 backtest 老股），都要在 case 末尾的「检讨」段落明确写出：

1. 哪些 dealbreaker / 评分维度判断对了？
2. 哪些维度漏看 / 错判了？
3. 这种漏看 / 错判属于哪类偏差（保守 / 机械 / 静态 / 风格）？

每累积 5 个新 case，看看是否有新的 systemic pattern——如果有，回到 SKILL.md 加规则；如果没有，说明框架在当前阶段稳定。
