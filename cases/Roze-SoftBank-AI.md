## Step 3 — 业务与行业位置

- **业务（按已公开计划）**：
  - 用**自主机器人 + AI** 加速建设美国数据中心（解决 AI infra 建设的劳动力短缺）。
  - 整合 SoftBank 既有资产：
    - **ABB Robotics 部门**（2024 收购，价 $5.4B）
    - **Ampere Computing**（2024 收购，价 $6.5B）
    - **DigitalBridge** 部分股权（$3B）
    - 部分 SB Energy（数据中心 + 可再生能源）
  - 与 OpenAI / Oracle 合作的 **Stargate 项目**（$500B AI infra 投资计划）相关。

### 🔍 行研话术核查
- "AI 基建 + 机器人"——叙事极强，但**目前是资产打包、不是产品**。
- 没有 Roze 品牌的实际收入、产品、客户披露。
- "解决数据中心建设劳动力短缺"——理论上对：美国数据中心 capex 2025-2030 复合增速 25%+，建造瓶颈是真问题。
- 但**机器人能否真把工地工人替代掉**——技术成熟度未验证。

## Step 3.5 — Pre-IPO 历史核查

🟡 SoftBank 操盘——**孙正义历史 IPO 操作复杂**：WeWork 撤回、Arm 上市后 +50% 但有过 -25% 回调、Coupang 上市后股价腰斩。**估值锚定能力强，但二级市场表现波动大**。
🟡 资产打包 IPO 模式（"Roll-up + IPO"）——估值通常 **= 各资产收购价之和 + AI 故事溢价**。从已披露数字粗算：$5.4B + $6.5B + $3B = $14.9B 收购成本，**$100B IPO = 6.7× 资产成本溢价**。
🔴 **内部对估值有分歧**——FT/CNBC 都报道 SoftBank 部分高管对 $100B 时间表表示"质疑"。这通常意味着实际 IPO 价大概率比目标低 30-50%。
🟢 与 OpenAI/Oracle 的 Stargate 关系是真切信任背书。

## Step 4 — 财务轨迹

**未披露**。可能的财务结构（基于资产组合推断）：
- ABB Robotics 部门 2024 收入估 ~$3B（之前 ABB 报告披露）
- Ampere Computing 收入估 ~$300M（云 ARM CPU 后期市场份额有限）

**关键问题（等 S-1 回答）**：

## 反哺 SKILL.md 的经验

1. **Step 0 应明确加入 "Pre-S-1 / Pre-招股书" 第五档时间窗口**。当前 SKILL.md Step 0 只有 4 档（before / within / closed / listed），漏掉了"还没递表"这种远期前瞻分析场景。
2. **资产打包 IPO（Roll-up IPO）应作为单独的子模式**——估值锚是"各资产收购成本 + 整合溢价"，不是常规 PS / PE。建议 prospectus-checklist.md 加 "deal type" 分类（普通 IPO / SPAC / Roll-up / 18A / 18C）。
3. **远期 IPO 分析应禁止给"立场"**——只能给"待 S-1 重评"。模板里要有 explicit "watching only" 状态，避免误导用户。
4. **关注上游母体股价**（如 SoftBank 9984.T）作为远期 IPO 的间接观察口——这种**衍生信号**应在 SKILL 里单独提一下。
